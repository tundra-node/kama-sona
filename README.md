# kama sona
kama sona — a tiny offline toki pona app for Android (minSdk 24).

Built for SM-G920P: dictionary (lipu Linku), own SM-2 SRS, trainer glosser, daily journal + streak + word-of-the-day, couples words.

- Package: com.elias.kamasona
- Data: CC BY-SA 4.0 (lipu Linku). nasin-nanpa font MIT.
- Source: see app/src/main, tools (data/build scripts), assets (dictionary + audio).
- SRS: own SM-2, card order randomized, deck column (extensible).
